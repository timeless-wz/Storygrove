# 正文写作两级目录 — 实施与验收

日期：2026-10-02。范围：用户确认的草稿箱／正文章节入口、二级卷目录、新增卷与章节、移动归卷。

## 行为

- 主侧边栏仅保留草稿箱和正文章节两个入口，不列具体章稿。
- 点击入口打开二级卷目录。卷默认折叠；卷名只选中卷，箭头才展开章节。空卷保留显示。
- 草稿箱仅列未归档草稿；正文章节仅列定稿。点击具体章节打开正文编辑器，原有保存失败阻止切章的保护保留。
- 二级目录顶部只有添加卷；选中或展开具体卷后才显示卷内添加章节，不提供外层添加章节。未归卷章节可移动到卷。新建窗口支持章节号和章节名称。
- 卷与章稿提供删除入口。删除卷先确认，卷内章稿移到未归卷；删除这一稿先确认，定稿走原有发布删除与派生清理流程。
- 新章节先创建草稿；定稿后进入正文章节，卷归属不变。同一章的草稿版本和定稿共享卷归属。
- 新增章节拒绝占用已有章号，避免意外修改旧章节的卷归属。创建失败保留对话框；移动失败保留目标选择。

## 数据与安全边界

`chapter_volume_assignments` 是正文独立归卷的持久化记录，不创建或改写章节蓝图。旧章节没有独立记录时仍沿用显式蓝图绑定的卷信息；独立记录优先，null 明确代表未归卷，不再回落到蓝图卷归属。

新增正文与卷归属在同一个 SQLite 事务中写入。不存在的卷导致正文和内容记录全部回滚。最后一稿删除或清空正文时清理归卷记录。卷记录沿用项目现有卷表，空卷也可在二级目录中显示。

新 IPC `db:chapter-volume-list/set` 与 `db:prose-volume-list/delete` 经过既有项目路径和完整会话门禁；旧 lease 的读写均被拒绝。新建卷、新建章节、移动章节保留异步操作后的会话复核。

按卷导出的目录与提交前复核同步读取独立归卷记录：自由创作章节可按卷导出，预览后移动章节会拒绝过期导出。
