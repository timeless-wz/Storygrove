# 创作资料填写指南

先看“基础设定总览”了解各入口状态，再打开对应业务页面。每段正式资料只在一个主要位置维护；其他页面可以摘要或链接。页面中的 Markdown 编辑器支持长文、标题、列表、引用和表格。

旧资料拆分时，请保留来源文件名和原文标题。按“选择 → 预览 → 拆分到对应入口 → 保存 → 重新打开回读 → 确认旧内容已整理”处理。已有正文不自动覆盖；部分重叠时手工决定合并方式。未采用想法进入候选，不因文件名含“已确认”就自动成为正式事实。

需要用某条素材启发全书规划时，先保存记录，再在素材详情点击“基于此素材生成总纲候选”。该按钮只把当前选中的素材带入这一次总纲候选请求；结果仍需在“章节蓝图”审阅和确认。普通正文生成不会读取素材列表。

## 13 份资料的归位示例

| 来源文件 | 填写位置与拆分方式 |
| --- | --- |
| `00_创作方向.md` | 作品定位、目标读者、核心阅读体验、创作原则填“创作方向”；具体正文执行规则填“写作规范”。 |
| `01_已确认设定清单.md` | 按段落拆入“世界设定”“力量体系”“人物与关系”“故事前提”和“章节蓝图”的全书/分卷规划。保留每段原标题和来源文件名。 |
| `02_剧情总纲.md` | 详细内容放“章节蓝图 → 全书总纲”；从中另写简短的主角起点、目标、阻碍、优势和长线悬念到“故事前提”，不复制整篇。 |
| `03_里世界探索.md` | 共同规则放“世界设定”；区域与地点逐条放“地点与区域”，不要求先画地图；成长等级与能力机制放“力量体系”。 |
| `04_事件与遗境库.md` | 尚未采用内容放“素材与候选”，按事件/遗境等用途分类；已采用并已写入剧情规划的部分进入对应卷纲或章纲。 |
| `05_人物与关系.md` | 每个人物建一条“人物档案”，在档案的 Markdown 背景、个人能力、备注中填写详细内容；待设计部分明确标为待定或素材。关系在人物关系入口维护。 |
| `06_废案与漏洞记录.md` | 废止方案及原因放“废案”；尚未解决的漏洞、风险和处理记录放“问题记录”。 |
| `07_世界观后台.md` | 未确认的后台设想先放“素材与候选”，不因其描述完整或文件名而进入正式世界设定。 |
| `08_参考作品与借鉴边界.md` | 放在“创作方向 → 参考作品与借鉴边界”；具体写明借鉴哪些方面以及不采用什么。 |
| `09_爆点设计与情绪兑现.md` | 通用阅读体验原则放“创作方向”或“写作规范”；候选场景放“素材与候选”；已采用的场景进入对应卷纲/章纲。 |
| `10_第一卷剧情大纲.md` | 放在“章节蓝图 → 分卷卷纲”，确认它隶属第一卷后再保存。 |
| `11_第一卷逐章细纲.md` | 每章内容放在对应的“章节蓝图”条目。只使用显式绑定，不按相同章号猜测草稿关系。 |
| `12_叙述风格与正文规范.md` | 叙述视角、语言、文风、对话、描写、节奏和自检要求放“写作规范”。若有故事事实，拆回对应正式设定。 |

## 各入口一句话判断

- **创作方向**：为什么这样写，希望读者获得什么体验？
- **写作规范**：落到正文时怎样表达、遵守什么要求？
- **故事前提**：故事从哪里开始，主角要做什么，主要阻碍是什么？
- **世界设定**：所有人共同遵守的世界规则是什么？
- **力量体系**：能力如何产生、成长、受限并付出代价？
- **地点与区域**：这个地方是什么样，如何抵达，有什么资源和危险？
- **人物与关系**：这个人物是谁、想要什么、有什么缺陷和个人能力？
- **剧情规划**：全书、卷和章节准备发生什么？
- **信息与揭露**：作者确定了什么；人物和读者分别知道什么？
- **素材与候选**：哪些想法还没有被采用？
- **废案与问题**：哪些方案已废止，哪些问题仍待解决？

正式设定和人物档案是事实来源；素材、卷章规划和人物未来变化是计划或候选。未决定的真相保持待定。保存后可重新打开资料回读；如果保存失败，页面会保留编辑内容并显示错误。
