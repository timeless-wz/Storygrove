# 小说工作台导航信息架构

本文件定义应用的用户可见功能归属。它只调整入口与命名，不改变任何创作数据、审批边界或工作流的行为。

## 固定区域

| 位置 | 一级职责 | 包含功能 |
| --- | --- | --- |
| 顶部栏 | 项目级操作与全局窗口控制 | 当前项目、保存状态、新建、打开、导入小说、导出、缩放、帮助、主题、语言、窗口控制 |
| 左侧主导航 | 工作区切换 | 首页、创作、资料、知识库、角色；底部固定为任务、日志、模型、设置 |
| 左侧内容区 | 当前一级功能的二级树 | 项目总览置顶，其后为故事设定、创作规划、正文写作、资料库、项目管理；或资料、知识库、角色的各自内容 |
| 右侧参考栏 | 当前项目的跨域快捷入口 | 项目设定、角色、创作规划、创作资料、任务，以及单一的 AI 助手入口 |
| 底部工具栏 | 运行与诊断支持 | 任务队列、日志、模型状态 |

```text

│  └─ 角色档案
├─ 创作规划
│  ├─ 章节蓝图、章节脉络、故事时间线
│  └─ 伏笔管理、多地图地图册、世界
├─ 正文写作
│  ├─ 草稿箱
│  └─ 正文章节
├─ 资料库
│  └─ 项目文档、资料来源与审核、知识检索
```

## 归位规则

- 正文编辑器的卷章目录只展示真实草稿和正文章节，不生成仅有蓝图的占位项；正文优先使用独立的章节归卷记录；旧章节沿用显式蓝图绑定中的卷信息，其余归入“未归卷”。蓝图绑定与写作参考功能保留。

- “章节蓝图”“故事架构/世界观”“伏笔与叙事线索”是“创作”的二级内容，不在左侧作为一级菜单重复出现。
- “创作资料中枢”和“知识库”都服务资料使用，但前者负责经作者确认的来源、规则和章节上下文；后者负责本地索引与检索，因此保留为相邻的一级入口。
- 右侧只提供与当前项目相关的跳转和一个真实的 AI 助手入口；不再把多个仅执行“打开 AI 面板”的按钮伪装成不同功能。
- 顶部的“更多项目操作”收纳低频的导入和导出，避免与左侧工作区导航混杂。

### 正文写作的两级目录

主侧边栏仅提供“草稿箱”和“正文章节”入口，不展开章稿。点击后打开二级卷目录，分别列出未归档草稿或定稿；卷名用于选中卷，旁边的箭头用于展开章节。卷目录保留空卷，顶部只提供“添加卷”。选中或展开具体卷后，卷内才显示“添加章节”。

新增章节先成为可编辑草稿，并在同一个数据库事务中保存正文归卷记录；定稿后在正文章节中显示。正文归卷存储在 `chapter_volume_assignments`，不创建或改写章节蓝图。同一章的所有版本共享归属，明确选择“未归卷”会覆盖旧蓝图绑定的卷归属。移动章节不修改正文内容。创建目录章节时拒绝已占用的章号，防止意外改动已有章节及其卷归属。

卷目录为卷与章稿提供删除入口。删除卷需确认，章稿被明确移到“未归卷”；`prose_deleted_volumes` 记录正文目录中已删除的卷，避免默认卷在读取或重开时复现，规划数据仍保留。删除草稿沿用草稿仓储的保护规则，删除定稿沿用既有发布删除与派生清理流程。新建章节窗口提供章节号和章节名称；章名写入已有 `drafts.imported_title` 标题字段，正文目录及编辑器可以直接读取，不依赖章节蓝图。
