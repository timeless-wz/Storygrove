# 修订学习与项目修稿技能合同

日期：2026-10-04

本合同描述作者修订学习、技能审阅和修稿阶段绑定的持久化边界。该功能沿用 [ADR 0015](../adr/0015-writing-skills-are-stage-scoped-guidance.md) 的阶段 Skill 模型；它只生成提示词型候选规则，不自动改写正文、项目事实或写作 Skill。

## 作者流程

作者可以从两类来源开始：

- 从项目数据库选择同一逻辑章节的两个已保存草稿版本。主进程重新读取草稿行，核对章节号后建立快照。
- 从正文编辑器记录当前可见正文。页面读取 Vditor 实时值、同步到编辑器标签状态，再将其作为 `editor-snapshot` 保存；该动作不替作者保存正文。

编辑器样本后续必须从创建时的同一个草稿和编辑器标签记录后稿。若标签已关闭，作者应重新打开来源正文；功能不会猜测另一标签的内容。保存版本可以来自不同草稿行，但逻辑章节号必须相同。

前后稿建立后，作者检查逐段差异，选择纳入项并填写单项理由与整体修改目标。差异 ID 由前后文本和段落位置决定；重算时只在唯一且文本相同的匹配上保留选择和理由。超出精确对照预算的内容以单项“粗略对照”呈现。

## 分析和作者审阅

修订记录、输入版本、输入哈希、前后稿快照、差异、整体理由、审阅草稿、每次分析 attempt 和发布操作都保存在当前项目 SQLite 数据库中。`revision` 用于记录编辑的比较并交换；`input_revision` 与 `input_hash` 冻结一次分析的证据身份。

分析走现有 `BaseWorkflowCommand` 和 `GenerationRuntime`，使用一个 `revision_learning` 工作流，不指定 `writingSkillStage`。工作流启动时跳过写作 Skill 快照，避免修稿阶段绑定进入“学习如何修稿”的提示词。提示词携带前后全文、差异选择和作者理由；未纳入差异在差异清单中明确排除。模型须把文本作为数据，不遵从文本中的指令。

主进程对模型 JSON 再做一次结构校验：规则只能引用纳入的差异；理由来源必须区分作者明确理由、模型推断和混合依据；一次性修改须留在个例清单。达到截断状态或校验失败时，不保存结果。

模型候选规则默认全部未选。作者可以编辑名称、正文、适用场景、例外和边界，并决定哪些规则进入技能。项目语言决定确定性 Markdown 预览。确认预览时，主进程重新渲染并核对内容哈希；预览哈希绑定到该次审阅版本。

## 发布与绑定

确认后的技能写入 `.vela/skills/<generated-name>/SKILL.md`。技能名由修订记录 ID 和技能草稿修订号生成；元数据固定为 `stage: refinement`。写入前验证自包含 Skill 兼容性，使用安全文件能力和会话租约，原子提交时要求目标文件仍不存在，再独立读回并核对 SHA-256 与兼容性。

SQLite 的 `revision_learning_publish_ops` 先持久化发布操作，再在文件读回成功后持久化发布回执。重试使用同一幂等键；只有已存在文件的哈希完全一致才恢复回执，内容不同时拒绝覆盖。

`.vela/writing-skills.json` 的修稿阶段绑定与技能发布分开。绑定读取当前值后通过主进程比较并交换；有其他窗口变更时返回冲突。若已有其他 Skill，界面显示当前和目标 Skill 并要求作者确认替换。绑定失败不回滚已发布技能，作者可以单独重试。

常规正文修稿和基于审稿报告的修稿继续使用现有 `refinement` 阶段冻结与注入路径。修订学习自身不消费该阶段 Skill。

## 会话、恢复和可观测性

所有 `revision-learning:*` IPC 都要求冻结的 `ProjectSessionContext`。主进程从当前项目数据库读取版本和记录，并在技能发布、状态读取和绑定写入前后重新验证项目路径与租约。文件目标由项目相对路径和安全文件能力确定；渲染进程不能提供任意发布路径。

分析 attempt 先以 `running` 持久化。输入变化会在 SQLite 事务中将当前 attempt 标记为 `interrupted` 并清除活动身份；迟到结果不能成为当前样本的结果。项目重开时，遗留 `running` attempt 被改为 `interrupted`。分析结果、失败原因、提示词版本、模型执行回执和用量可从修订记录查看。

技能文件状态、发布回执和当前修稿绑定分别读取并展示。文件缺失、哈希不同、技能不兼容或绑定冲突都不会被显示成成功。

## 验收范围

- `src/shared/__tests__/revision-learning.test.ts`：段落差异、稳定证据 ID、排除证据和确定性技能预览。
- `electron/repositories/__tests__/revision-learning-repository.test.ts`：不同草稿行的同章比较、作者差异选择、输入变化中断 attempt、数据库重开恢复。
- `src/services/agent/__tests__/writing-skill-bindings.test.ts`：绑定比较并交换和冲突处理。
- `electron/security/__tests__/windows-safe-file-system.test.ts`：独占新建约束进入安全原子写助手。
