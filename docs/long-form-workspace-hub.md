# 长篇小说创作中枢（Workspace Hub）技术与使用手册

## 一、产品定位与核心目标

“长篇小说创作中枢”是为两百万字量级长篇连载小说设计的创作中台模块，核心解决长篇小说写作中面临的四大痛点：
1. **母稿与事实分离**：作者习惯在本地 Markdown 文件中构思草稿、梳理设定，但模型推理需要结构化、强约束的 SQLite 运行事实。
2. **严防污染与废案乱入**：创作过程中会产生大量“废案”与“待确认候选”，若被一股脑丢给大模型，会导致模型产生幻觉，误用废弃设定。
3. **出场人物失控**：长篇小说出场人物众多，必须由作者在导入前显式预览、比对差异并主动确认，严防模型或后台擅自污染正式角色名单。
4. **长上下文确定性装配**：长篇小说写到第 N 章时，不能无脑拼接全文，而必须经过确定性 13 阶段筛选、预算控制、章节范围匹配与陈旧检查。

## 二、双层架构与只读安全契约

系统采用严格的“双层事实架构”与“单向流转安全模型”：

```
+-------------------------------------------------------------+
|               外部创作母稿目录 (Author Workspace)              |
|   (如 00_创作方向.md, 01_设定.md, 05_人物.md, 11_细纲.md ...)    |
|               【绝对只读 READ-ONLY，零回写、零删除】              |
+-------------------------------------------------------------+
                              |
                     [只读扫描与增量哈希]
                              v
+-------------------------------------------------------------+
|                中枢解析与候选池 (Workspace Hub)                |
|   - 标题面包屑树 (Heading Paths) 与行号范围 (Lines & Hash)       |
|   - 待确认候选池 (Import Candidates: 角色卡 / 设定项)            |
|   - 设定规则库 (Setting Rules: 已确认 / 候选 / 后台 / 废案)       |
+-------------------------------------------------------------+
                              |
                     [作者显式预览与批准]
                              v
+-------------------------------------------------------------+
|                系统运行事实源 (SQLite Authority)               |
|   - 角色事实名单 (characters & characters_arch 投影)          |
|   - 章节蓝图与正文上下文 (blueprints, drafts)                    |
+-------------------------------------------------------------+
```

### 只读安全红线
1. **绝对只读**：外部目录无论何时只能读取，系统绝对不调用写文件、重命名、移动或删除外部文件的 API。
2. **解除绑定安全**：解除母稿目录关联或删除系统项目时，仅清除数据库内的路径标记和索引缓存，**绝对不级联删除外部母稿文件**。
3. **路径不硬编码**：系统绝不硬编码任何开发或验证路径，全部通过 Electron 目录选择对话框由用户动态指定。
4. **非破坏性容错**：当外部文件被移动或删除时，重新扫描会将来源标记为 `is_missing = 1`，原有解析片段与历史规则予以保留，绝不崩溃或级联抹除。

## 四、四级权威划分与角色审批流

### 1. 设定规则四级权威划分
- **已确认 (`confirmed`)**：通过作者核定，具备最高法律效力的世界事实，直接参与正文上下文。
- **候选 (`candidate`)**：作者正在构思或扫描自草稿的内容。进入上下文时**必须携带 `[待确认/候选]` 警示前缀**，提醒模型不可作为定论。
- **后台 (`background`)**：作为世界底色，仅在章节强相关或有余裕时补充，不默认大段塞入。
- **废案 (`deprecated`)**：**最高排除保护**。无论在规则库还是母稿片段中，废案内容绝不出现在生成提示词的正向内容块中。

### 2. 角色候选审批与原子提交
从 `05_人物与关系.md` 中提取的角色名与关系，会自动生成 `candidate_type = 'character'` 的导入候选：
1. **候选池预览**：在中枢【资料】页点击“查看候选”或在弹窗中查看提取的角色名、身份、性格、能力与关系。
2. **差异比对 (Diff)**：展示候选字段与当前运行数据库中同名角色的字段差异。
3. **作者显式确认**：作者点击【确认导入】后，后端通过 `CharacterRosterRepository.commit`（带 `manual_edit` 意图）执行单事务提交：
   - 插入或更新 `characters` 表；
   - 重新生成 `characters_arch` 角色图谱投影；
   - 将候选状态更新为 `approved`。
4. 未确认角色绝不写入系统正式角色库。

## 五、确定性 13 阶段章节上下文包装配

当为目标“第 N 章”装配写作材料时，中枢装配引擎（`ChapterContextAssembler`）按确定性阶段执行，并在预算字符限制内裁切：

1. **Stage 1: 创作总则**：提取 `00_创作方向.md`，确立全书基调与核心审美。
2. **Stage 2: 剧情总纲与长线目标**：提取 `02_剧情总纲.md`，锚定当前卷在全书中的位置与长线悬念。
3. **Stage 3: 卷级大纲**：提取 `10_第一卷剧情大纲.md`（或对应当前卷的文件）。
4. **Stage 4: 当前逐章细纲**：精准匹配第 N 章细纲（支持 `11_第一卷逐章细纲.md` 内的章节范围 `[第1-5章]`、`## 第1章` 或子文件 `第001章.md`）。
5. **Stage 5: 当前章节目标与情绪兑现**：提取 `09_爆点设计与情绪兑现.md` 中关于本章的高潮与爽点安排。
6. **Stage 6: 已确认世界设定**：提取权威状态为 `confirmed` 的规则，排除所有废案。
7. **Stage 7: 当前章节出场人物与关系**：提取正式角色库中本章核心人物与动态状态。
8. **Stage 8: 世界资料与景观玩法**：提取 `03_里世界探索.md` 的场景与探索规则。
9. **Stage 9: 事件与遗境素材**：提取 `04_事件与遗境库.md` 中的候选遭遇。
10. **Stage 10: 后台与关联设定**：在预算允许时，补充 `07_世界观后台.md` 中的深层背景。
11. **Stage 11: 参考作品与借鉴边界**：提取 `08_参考作品与借鉴边界.md`，列明禁区与风格对标。
12. **Stage 12: 前文摘要与连续性**：提取前序章节定稿摘要，确保剧情紧密咬合。
13. **Stage 13: 叙述风格与正文规范**：提取 `12_叙述风格与正文规范.md`，在提示词末尾强化语言、排版与描写禁忌。

### 预算控制与陈旧预警
- **预算控制 (Budget Caps)**：默认 16,000 字符（可调）。若内容超长，自后向前（优先保留前 7 阶段核心纲要）进行受控省略，并在省略清单中明确记录 omitted stages 及原因。
- **陈旧预警 (Stale Warnings)**：若外部文件发生修改使得哈希与数据库索引不一致，装配结果会亮起黄灯提示“某文件已修改，建议重新扫描”，但不会中断写作。
- **无缝衔接工作流**：在【章节上下文】界面点击【存为本章蓝图材料】，即可一键同步至当前章节的“用户指导要求”中，驱动现有生成工作流。

## 六、用户界面（UI）操作指南

1. **入口**：在左侧主导航栏点击【中枢】（指南针图标 `Compass`）。
2. **母稿关联**：
   - 首次进入点击【关联外部创作母稿目录】，在弹出的系统目录选择器中选中小说本地文件夹。
   - 系统自动开始深度只读扫描，展示扫描统计（文件数、片段数、识别率）。
3. **三大标签页**：
   - **资料 (Materials)**：
     - 左侧列出所有已扫描母稿文件，带有分类徽章、权威度、状态（正常 / 已变化 / 缺失）。
     - 右侧展示选定文件的标题树、行号范围与内容预览。
     - 顶部提供【查看提取候选】按钮，点击打开候选审批弹窗。
   - **设定 (Setting Rules)**：
     - 支持按【全部 / 已确认 / 候选 / 后台 / 废案】进行状态筛选。
     - 支持快捷卡片操作：直接将候选设为已确认、提升为硬约束、或转为废案。
   - **章节上下文 (Chapter Context)**：
     - 顶部输入目标章节号（例如“1”）与字符预算（例如 16,000）。
     - 点击【装配本章上下文包】，系统毫秒级输出 13 阶段结构化拼装内容。
     - 界面直观展示总字数、预算进度条、陈旧预警、候选提示与省略清单。
     - 提供【复制全文】和【存为本章蓝图材料】按钮。
4. **主页集成**：在【首页】（WelcomePage）新增了“创作母稿中枢”卡片，显示当前关联目录与状态，支持一键直达。
